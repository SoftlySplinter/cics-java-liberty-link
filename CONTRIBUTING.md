# How to contribute

Thank you for your interest in this project!

> [!NOTE]
> At this time, we only accept bug reports through the issue tracker. We are not accepting pull requests or code contributions.

## Reporting a bug

Please raise bugs via the issue tracker. First, check whether an issue for your problem already exists.

When raising bugs, please include:
- What you were doing when the bug occurred
- What you expected to happen
- What actually happened
- Any relevant logs, error messages, or screenshots
- Your environment details (CICS version, z/OS version, etc.)
